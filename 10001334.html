2026 햇수미감자

대국민상회 | 신선한 제철 먹거리
상품 설명
배송사 : CJ/롯데/로젠/한진

우리나라 감자 생산량의 대부분을 차지하는 가장 대중적인 품종입니다.

특징: 분질과 점질의 중간 성질을 가지고 있습니다. 적당히 포슬하면서도 잘 부서지지 않습니다.

용도: 조림, 국, 찌개, 볶음 등 모든 한국 요리에 무난하게 잘 어울립니다.

맛: 저장성이 좋고 맛이 깔끔해서 '국민 감자'로 불립니다.

감자 규격
- 소+중 : 40g 이하
- 중 : 50~80g / 수량 : 15개 내외 (1kg 기준) / 조림 & 알감자용 (휴게소 알감자)
- 대 : 80~110g / 수량 : 9개 내외 ( 1kg 기준) / 알감자 & 찜용 (달걀 크기)
- 특 : 110~160g / 수량 : 7개 내외 (1kg 기준) / 찜&요리용 (테니스공 크기)
- 왕특 : 160~210g / 수량 : 4개 내외 (1kg 기준) / 혼합요리용 (야구공 크기)
- 왕왕 : 220g 이상 / 수량 : 3개 내외 (1kg 기준) / 식당/부침개용
